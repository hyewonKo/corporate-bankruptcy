# 한국 회사채 시장에서 스프레드는 신용 리스크를 제대로 반영하고 있는가?
### Merton 모델 기반 이론 스프레드와 ML 부실 예측 PD의 통합 신용 분석 프레임워크

---

## 0. 프로젝트 전체 구조

본 연구는 두 프로젝트가 유기적으로 연결된 통합 신용 분석 패키지다.

```
[사이드 프로젝트]                         [메인 프로젝트]
ML 기반 부실기업 예측                      Merton 기반 스프레드 분석
──────────────────                         ──────────────────────────
재무제표 → XGBoost                         주가·부채 → BSM 역산
→ ML-PD 산출                    ──→        → EDF(시장 내재 PD) 산출
                                           → 이론 신용 스프레드 산출
                                           → 실제 스프레드와 비교
                                ──→
                        [통합 분석]
                ML-PD vs. EDF 괴리 분석
                괴리 발생 구간 = 핵심 리스크 신호
                → 크레딧 리서치 리포트
```

두 모델이 **동의하는 구간**은 신뢰도 높은 경보 신호이고,  
두 모델이 **괴리를 보이는 구간**이 본 연구의 핵심 분석 대상이다.

---

## 1. 연구 배경

### 신용 리스크를 보는 두 가지 시각

신용 리스크를 측정하는 방법론은 크게 두 패러다임으로 나뉜다.

| 구분 | 접근 방식 | 데이터 | 대표 모형 |
|------|----------|--------|----------|
| 축약형 모델 | 재무 데이터의 패턴으로 부실 예측 | 재무제표 (분기 업데이트) | Logistic, XGBoost |
| 구조적 모델 | 자산 가치와 부채 구조로 PD 도출 | 주가·시총·부채 (실시간) | Merton, KMV |

실무에서는 두 모델을 병행하지만, 각각을 독립적으로 활용하는 데 그치는 경우가 많다. 본 연구는 두 모델의 결과를 **동일 기업군에 동시에 적용하고 직접 비교**함으로써, 어느 모델이 어떤 국면에서 신용 리스크를 더 잘 포착하는지 실증한다.

### 한국 회사채 시장의 구조적 특수성

한국 회사채 시장은 재벌 계열사의 암묵적 보증, 정책금융 개입, 코스닥 소형주의 유동성 제약 등 고유한 요인으로 인해 시장 가격이 실제 신용 리스크를 왜곡할 가능성이 높다. 2022년 레고랜드 사태, 2020년 코로나 충격 등 실제 위기 국면에서 회사채 스프레드는 단기간에 급등락을 반복했으며, 이 움직임이 기업 펀더멘털을 반영한 것인지 시장 과잉반응인지를 판별할 이론적 기준이 부재했다.

---

## 2. 연구 목적

사이드 프로젝트에서 구축한 **ML 기반 부실 예측 모델(ML-PD)** 을 기반으로, Merton 모델에서 산출한 **시장 내재 부도확률(EDF)** 과 **이론 신용 스프레드**를 결합한다. 두 PD 지표를 동일 기업군에 적용해 한국 회사채 시장의 스프레드 괴리를 실증 분석하고, 괴리가 투자 기회인지 구조적 왜곡인지 크레딧 리서치 관점에서 해석하는 것을 목표로 한다.

---

## 3. 연구 가설

**H1. 이론 스프레드와 실제 스프레드 사이에는 유의미한 괴리가 존재한다**

한국 시장 고유의 구조적 요인(정책금융, 재벌 보증, 유동성 프리미엄)으로 인해 실제 스프레드는 Merton 이론 스프레드와 체계적으로 다르게 형성된다.  
*근거: Merton(1974), 신용 스프레드 퍼즐(Credit Spread Puzzle) 선행연구*

**H2. Spread Gap의 패턴은 섹터별로 구조적으로 상이하다**

건설·유통·에너지 등 업종별로 Spread Gap의 방향과 크기가 다르게 나타나며, 이는 섹터별 신용 특성과 정책 노출도의 차이를 반영한다.  
*근거: 산업별 신용 리스크 이질성 이론*

**H3. ML-PD와 EDF의 괴리 구간은 추가적인 신용 리스크 신호다**

두 모델이 동의하는 구간보다 크게 괴리를 보이는 구간에서 회계 이슈·정책 개입·시장 충격 등 특정 리스크 요인이 집중된다.  
*근거: 구조적 모델 vs. 축약형 모델 비교 선행연구*

**H4. Spread Gap은 신용등급 변동의 선행 신호다**

등급 강등 전 Spread Gap이 확대되는 패턴이 존재하며, 시장이 공식 신용등급보다 리스크를 먼저 반영함을 시사한다.  
*근거: 신용등급 후행성 관련 선행연구, Event Study 방법론*

---

## 4. 연구의 독창성

### 두 프로젝트를 하나의 분석 파이프라인으로 통합한다

사이드 프로젝트(ML 부실 예측)에서 산출된 ML-PD는 본 연구에서 Merton EDF와 비교되는 독립 변수로 직접 활용된다. 단순히 두 모델을 나란히 제시하는 것이 아니라, ML-PD와 EDF의 **괴리 자체를 새로운 신용 리스크 지표**로 정의하고 분석하는 것이 핵심이다.

### 괴리(Spread Gap)를 정보로 해석한다

대부분의 선행연구는 Merton 모델의 예측 정확도를 평가하는 데 그친다. 본 연구는 괴리가 발생하는 구간과 맥락을 분석해, "모델이 틀렸다"가 아닌 "괴리 자체가 정보다"라는 크레딧 리서치 관점의 결론을 도출한다.

### 한국 시장 특수성을 정면으로 다룬다

재벌 계열사의 암묵적 보증, 정책금융 개입, 코스닥 소형주의 유동성 왜곡이 이론 스프레드와 실제 스프레드의 괴리를 어떻게 형성하는지 직접 실증한다. 해외 논문을 그대로 재현한 프로젝트와 구별되는 지점이다.

### 실제 시장 사건으로 검증한다

레고랜드 사태(2022), 코로나 충격(2020), 금리 급등기(2022) 등 실제 위기 구간에서 Spread Gap과 ML-PD·EDF 괴리가 어떻게 움직였는지 사후 검증해 프레임워크의 현실 적용 가능성을 실증한다.

## 5. 분석 프레임워크

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[사이드 프로젝트에서 가져오는 것]
재무비율 (이자보상배율·부채비율·유동비율 등)
→ XGBoost 부실 예측 모델
→ ML-PD (기업별·분기별 시계열)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
        ↓ 동일 기업군에 병행 적용
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[메인 프로젝트 — Merton 산출]
주가·시가총액 (FinanceDataReader)
부채 장부가 (DART API)
→ BSM 연립방정식 수치 역산 (scipy.optimize)
→ 자산 가치 V, 자산 변동성 σ_V
→ Distance to Default (DD)
→ EDF = N(-DD)
→ 이론 신용 스프레드
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
        ↓
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[통합 분석]
Spread Gap = 실제 스프레드(KOFIA) − 이론 스프레드
PD Gap     = ML-PD − EDF

① 섹터별 Spread Gap 분포 및 패턴
② 신용등급 변동 전후 Event Study
③ 거시 환경 구간별 비교 (금리·경기·유동성 충격)
④ PD Gap이 큰 기업군의 공통 특성 분류
   → 회계 이슈 / 시장 충격 / 정책 개입
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
        ↓
[OUTPUT]
크레딧 리서치 리포트 + Streamlit 대시보드
```

## 6. 분석 유니버스

코스피 상장 + 회사채 발행 이력 보유 기업으로 한정한다.

| 섹터 | 대표 기업 | 선정 이유 |
|------|----------|----------|
| 건설 | 현대건설, GS건설 | 2022~2023년 스프레드 급등 — 괴리 분석 포인트 풍부 |
| 유통 | 롯데쇼핑, 이마트 | 내수 경기 민감도 높아 ML-PD·EDF 반응 차이 관찰 용이 |
| 에너지 | SK이노베이션, 한국전력 | 정책금융 개입 구조 — 스프레드 왜곡 분석 가능 |
| 통신 | KT, SKT | 안정적 신용 등급 — 벤치마크 및 비교군 역할 |

## 7. 사용 데이터 및 기술 스택

| 구분 | 데이터 출처 | 활용 내용 |
|------|-----------|----------|
| 주가·시가총액 | FinanceDataReader | 일별 주가, 250일 rolling 변동성 |
| 재무제표 | DART OpenAPI | 분기별 부채·이자비용·재무비율 |
| 회사채 수익률 | KOFIA | 등급별·만기별 회사채 수익률 |
| 국고채 금리 | 한국은행 ECOS | 무위험이자율 기준선 |
| 신용등급 이력 | 한국신용평가, NICE | 등급 변동 전후 Event Study용 |

```
Python 스택
├── 데이터 수집   pandas / FinanceDataReader / DART API / requests
├── Merton 역산   scipy.optimize / numpy / scipy.stats
├── ML 모델       scikit-learn / XGBoost (사이드 프로젝트 연계)
├── 분석          statsmodels / pingouin (Event Study)
└── 시각화        plotly / seaborn / Streamlit
```

## 9. 포트폴리오 포지셔닝

> **사이드 프로젝트**: 재무제표 기반 ML 부실 예측 모델 → ML-PD 산출  
> **메인 프로젝트**: Merton 기반 시장 내재 신용 리스크 분석 → EDF·이론 스프레드 산출  
> **통합 스토리**: 두 패러다임을 동일 기업군에 적용해 한국 회사채 스프레드의 구조적 괴리를 실증 분석

두 프로젝트는 같은 질문(이 기업, 얼마나 위험한가?)에 서로 다른 방법론으로 접근한다.  
그 차이를 비교하고 해석하는 것 자체가 크레딧 리서치의 본질이며, 이 프로젝트의 핵심 메시지다.
